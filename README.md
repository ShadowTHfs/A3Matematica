# Desafio Algébrico — Rumo ao ENEM

Protótipo de jogo educativo de Álgebra para Ensino Médio e preparação para o ENEM.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro
- Sem banco de dados na primeira versão

## Como testar
Abra `index.html` no navegador.

## Como publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Entre na Vercel e importe o repositório.
4. Framework Preset: **Other**.
5. Build Command: deixe vazio.
6. Output Directory: deixe vazio.
7. Clique em Deploy.
